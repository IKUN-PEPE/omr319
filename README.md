# OMR319

https://omr319.xcgaming.net/ 的本地 1:1 镜像（OMR319 鼠标网页配置工具）。

## 镜像说明

- 共 21 个文件，约 2.16MB，全部抓取自原站（腾讯云 COS 静态托管）
- 首页文件与原站服务器返回内容逐字节一致（MD5 与原站 ETag 相符）
- 浏览器实测：本地渲染结果与线上页面内容完全一致
- 纯静态站点（Next.js 静态导出 + Chakra UI），不依赖任何服务器端接口，可直接用任意静态服务器托管

## 目录结构

```
├── index.html           # 首页
├── 404.html             # 404 页面
├── main_bkg.png         # 背景图
├── products/mouse.png   # 鼠标产品图
├── icon/                # 小图标
├── wave.svg
├── favicon.ico
└── _next/static/
    ├── css/             # 样式
    └── chunks/          # JS 文件（其中 234 / 249 是中文、英文文案数据）
```

## 运行方式

```bash
python -m http.server 8319
```

然后用 **Chrome 或 Edge** 打开 http://127.0.0.1:8319/ （页面本身注明仅支持这两个浏览器）。

## 使用

- 点击页面上的"立即连接"会弹出鼠标设备选择框（WebHID 接口），接上真实的 OMR319 鼠标即可进入配置界面（模式、电量、按键、DPI、宏、灯光等）
- 右上角可切换中文 / English
- 配置界面依赖真实鼠标，未接鼠标时页面停留在欢迎页
